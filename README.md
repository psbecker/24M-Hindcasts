# 24M-Hindcasts
Recreates Most Probable, Probable Max, and Probable Min 24 Month Study hindcasts
Includes input files for water years 1982 through 2020.

First part of the code creates monthly ESP traces for the 10th, 25th, 50th, 75th, and 90th percentiles.

Then, using the Historical values and ESP, the Most Probable, Probable Max, and Probable Min are created for each month.
